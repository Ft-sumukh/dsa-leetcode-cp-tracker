## 🎯 Progress Rules & Progression

We prioritize: **Understanding > Independent solving > Pattern recognition > Speed > Problem count**

### Problem Solving Mastery Stages
1. **New** 🆕 (Problem discovered / noted)
2. **Attempted** ⏳ (Tried, but not yet accepted or required heavy assistance)
3. **Solved** ✅ (Accepted code submitted)
4. **Reattempt** 🔄 (Marked to be resolved independently later)
5. **Mastered** 👑 (Can explain the approach, why it works, implement it, analyze time/space, and handle edge cases independently)

### Topic Confidence Levels
`Not Started` ➡️ `Learning` ➡️ `Practicing` ➡️ `Strong` ➡️ `Interview Ready`
